# Installation

1. Install Typewriter on your server.
2. Place `WaypointRPGExtension-1.0.0.jar` in:

```txt
plugins/Typewriter/extensions/
```

3. Restart the server.
4. Open the Typewriter panel.
5. Create one of the WaypointRPGExtension entries.

## Optional BetterHUD setup

If you use BetterHUD:

1. Install BetterHUD.
2. Create or choose a compass element in your BetterHUD layout.
3. Add a `waypoint_betterhud_bridge` entry in Typewriter.
4. Set the bridge icon name to match your BetterHUD compass element.

## Updating

Replace the old `.jar` with the new one and restart the server.

For Typewriter snippet changes, `/tw reload` is enough.
