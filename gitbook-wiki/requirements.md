# Requirements

| Component | Required |
|---|---|
| Paper / Purpur | `1.21.1+` |
| Java | `21+` |
| Typewriter | `0.9.0-beta-173` or compatible |
| PacketEvents | Required by Typewriter / packet display handling |
| BetterHUD | Optional, only for compass integration |

## Optional integrations

### BetterHUD

Install BetterHUD only if you want the active waypoint to appear on a compass element.

### Resource packs

Resource packs are optional. They are only needed if your text/icon uses a custom font or custom glyph.

## Client requirements

Players do not need Fabric, Forge, or any client-side mod.
