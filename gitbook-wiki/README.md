# How to Start

WaypointRPGExtension adds RPG-style waypoint visuals to Typewriter quests.

The extension is made for server owners and quest configurators who want clear objective guidance without requiring players to install a client mod.

## What it can show

- Floating waypoint text.
- A custom icon or resource-pack glyph.
- A vertical beam.
- Route points before the final objective.
- Zone enter and exit triggers.
- Optional BetterHUD compass points.

## First setup path

1. Check [Requirements](requirements.md).
2. Install the jar using [Installation](installation.md).
3. Build your first waypoint with [Waypoint Tutorial](waypoint-tutorial.md).
4. Tune every option with [Entry Configuration](entry-configuration.md).
5. Add compass or trigger behavior with [Integrations](integrations.md).
6. Customize arrows and glyphs with [Extras](extras.md).

## Entries included

| Entry | Use it for |
|---|---|
| `tracked_locatable_waypoint` | Main waypoint display: text, icon, beam, entities, and route points. |
| `waypoint_zone_trigger` | Run Typewriter triggers when a player reaches or leaves a waypoint area. |
| `waypoint_betterhud_bridge` | Send active waypoint targets to a BetterHUD compass. |

## Public version
