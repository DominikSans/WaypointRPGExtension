# What's New in v3.1.0

WaypointRPGExtension v3.1.0 keeps one global renderer and moves quest appearance,
paths, entities, proximity triggers, and BetterHUD synchronization into focused entries.

## Main changes

* One `static_waypoint` renders every active target for each player.
* `quest_waypoint` assigns a preset or reusable theme directly to a Quest.
* `waypoint_path` adds ordered checkpoints without duplicating styling fields.
* `entity_waypoint` supports Bukkit entities and Typewriter shared NPC instances.
* Entity glow is private per player and works with Bukkit and packet-only NPC IDs.
* `waypoint_theme` can override beam, label, symbol, shadows, and BetterHUD icon.
* BetterHUD remains optional and is accessed without a hard runtime dependency.
* Path progress is centralized, so renderer, zones, and BetterHUD use the same point.

## Visual improvements

* The symbol plays a one-shot focus acquisition effect when a target starts tracking.
* The two-layer beam supports a rotating inner core and full-bright rendering.
* Label and symbol remain upright and follow horizontal camera movement without pitch tilt.
* The restored V3 movement keeps displays smooth while sprinting or crossing long distances.

## Smart See-Through

Label and symbol are checked independently. The label samples its center, sides, top,
and bottom; the symbol samples its center and sides. Full opaque obstruction activates
the protected pass immediately. Leaves, doors, trapdoors, and partial shapes use
weighted coverage and short hysteresis to avoid flicker.

Glass, stained glass, tinted glass, and panes are ignored as transparent. The ray keeps
travelling, so a solid wall behind glass is still detected. The core shaders protect the
complete text quad, including multiline text and shadows, while keeping the beam behind
the label and symbol.

These safeguards are hardcoded and do not appear in the Typewriter panel. Debug logging
is temporarily disabled.

## Public entries

| Entry | Purpose |
|---|---|
| `static_waypoint` | Global label, symbol, beam, scaling, and bob renderer. |
| `quest_waypoint` | Quest-to-preset or Quest-to-theme association. |
| `waypoint_path` | Ordered checkpoints for one location objective. |
| `waypoint_theme` | Reusable advanced appearance overrides. |
| `entity_waypoint` | Bukkit entity or Typewriter NPC target with optional glow. |
| `waypoint_zone_trigger` | Enter and exit events around active targets. |
| `waypoint_betterhud_bridge` | Optional BetterHUD compass synchronization. |

`tracked_locatable_waypoint` remains archived in source for historical reference and is
not registered in the panel.
